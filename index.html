Features

功能列表

专注满足日常网络代理配置与分流需求

节点订阅与多源自动分组

支持导入 Clash YAML、Base64 订阅或直链，自动按订阅源隔离分组管理，支持定时自动静默同步与一键批量更新。

按规则自动分流与沙盒

支持通配符、关键词与正则表达式路由。内置分流沙盒模拟器，实时测试命中流向，未匹配自动走默认回退动作。

纯直连高速测速与分组选优

测速流量强制直连（绝不走自身代理造成回环），一键并发测速并支持优先在当前所选分组内部自动挑选最低延迟节点。

协议智能识别与环境适配

智能识别 HTTP/HTTPS/SOCKS5 原生直连与 VMess/VLESS 等隧道协议；针对 Firefox 完整支持 Ghelper 专线节点认证直连。

精品规则集一键导入

内置开发平台（GitHub/Docker）、AI 工具（OpenAI/Claude/DeepSeek）、全球流媒体与国内白名单等规则模板。

100% 本地安全存储与备份

所有节点、订阅和规则均保存在本地 storage 中，零第三方网络上报，支持 JSON 全量一键导入/导出跨设备无缝迁移。

Guide

安装与长期使用教程

请选择您使用的浏览器查看对应安装指引

Chrome / Edge 开发者模式载入（永久常驻）
推荐
1
下载 MEI-Proxy-Chrome.zip 并解压到本地文件夹。
2
在浏览器地址栏打开扩展管理页面：Chrome 输入 chrome://extensions，Edge 输入 edge://extensions。
3
开启页面右上角的「开发者模式」开关。
4
点击左上角「加载已解压的扩展程序」，选择第 1 步解压出来的文件夹即可完成安装。
方法一：开发版 / 衍生版直接安装（最简单 · 永久使用）
最方便
1
适用于 Firefox Developer Edition、Nightly、Floorp、Zen Browser、Waterfox 等浏览器。
2
在地址栏输入 about:config 并回车，点击接受风险。
3
搜索 xpinstall.signatures.required，双击将其值修改为 false。
4
在地址栏输入 about:addons，点击右上角齿轮图标，选择「从文件安装附加组件...」，选中下载好的 MEI-Proxy-Firefox.xpi 即可永久安装。
方法二：正式版 Firefox 通过本地策略常驻（永久使用 · 无需签名）
正式版免签方案
1
打开 Firefox 安装目录（通常为 C:\Program Files\Mozilla Firefox）。
2
在安装目录下新建一个名为 distribution 的文件夹。
3
在 distribution 文件夹内新建文件 policies.json，填入以下内容（将路径替换为您本地 xpi 的实际路径）： 
{
  "policies": {
    "ExtensionSettings": {
      "meiproxy@mei.local": {
        "installation_mode": "normal_installed",
        "install_url": "file:///C:/您的路径/MEI-Proxy-Firefox.xpi"
      }
    }
  }
}
4
重启 Firefox，扩展将作为企业策略永久载入，重启浏览器不会丢失。
方法三：临时载入（用于临时体验测试）
临时测试
1
在 Firefox 地址栏输入 about:debugging#/runtime/this-firefox。
2
点击「临时载入附加组件...」，选择 MEI-Proxy-Firefox.xpi 或解压文件夹内的 manifest.json 即可临时体验（浏览器完全关闭后需重新载入）。
